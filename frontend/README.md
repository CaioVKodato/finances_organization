# Frontend — finances_organization

Interface em React + Vite + TypeScript + Tailwind. Documentação geral e estrutura do repositório: veja [`../README.md`](../README.md).

```bash
npm install
npm run dev    # desenvolvimento
npm run build  # produção → dist/
```

Variável opcional: `VITE_API_URL` (URL base da API, sem barra no final).
